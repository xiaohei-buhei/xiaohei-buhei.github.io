# 打工人职场人格体检 · 在线版

一套可直接部署的趣味人格测试站。纯前端，无后端、无数据库、不收集作答内容。

- 16 道情境题 → 四维加权 → 8 种原型 / 16 种变体 → 结果页 + 可保存报告图
- 结果页内置三类变现位：广告位、深度版付费入口、公众号引流位
- 引擎结构参考开源项目 [ACGTI](https://github.com/tianxingleo/ACGTI)（Apache-2.0）二次创作，题库与文案为本项目原创

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架与文案结构 |
| `assets/quiz.css` | 全部样式（体检报告单视觉） |
| `assets/quiz-data.js` | 站点配置、题库、八种原型、计分参数 |
| `assets/quiz-app.js` | 计分引擎、结果渲染、海报导出、变现位挂载 |

## 发布到线上

### GitHub Pages

1. 推到 GitHub 仓库；
2. Settings → Pages → Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`；
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

仓库名为 `<用户名>.github.io` 时即个人根站，直接访问 `https://<用户名>.github.io`。

### Vercel / Netlify / 自有服务器

导入仓库即可，不需要构建命令；或把整个目录上传到站点根目录，静态访问不需要运行时。

## 变现配置：只改一个地方

打开 `assets/quiz-data.js`，搜索 `const SITE`，改完刷新即生效。留空 = 该模块不显示。

```js
const SITE = {
  brand: '',            // 公众号名，填了才出现「关注」模块
  wechatId: '',         // 公众号 ID 或微信号
  qrcodeUrl: '',        // 公众号二维码图片，例如 './qr.png'
  adClient: '',         // AdSense 发布商 ID：ca-pub-xxxxxxxxxxxxxxxx
  adSlotId: '',         // AdSense 广告位 ID
  unlockUrl: '',        // 深度版购买/领取链接
  unlockPrice: '¥9.9',  // 购买按钮显示的价格
  siteUrl: ''           // 站点地址，会写进分享文案
};
```

- **广告位**：结果页底部出现自适应广告，自动加载 AdSense；
- **深度版**：结果本身免费，只卖「下一步怎么做」（路径推演、话术模板、避坑清单），不做结果付费墙；
- **公众号引流**：结果页底部出现带二维码的关注卡，把一次性流量沉淀成可反复触达的粉丝。

## 变现方式与前提

1. **公众号导流 → 广告/互选/社群**：零门槛，今天就能开。
2. **深度版付费**：需要可收款主体（个人可用知识星球、小报童、微信支付商户号），建议 6.9–19.9 元区间测转化。
3. **AdSense 广告**：需自行申请并通过审核；GitHub Pages 二级域名通常难通过，正式接广告前建议换自定义域名并完成备案。
4. **品牌定制**：企业团建、招聘季可按单交付定制测评。

## 合规与边界

- 页脚已标注引擎来源，对外发布时保留「基于 ACGTI 项目二次创作」的说明；
- 明确写「娱乐测试，不构成心理诊断或人岗匹配依据」；
- 面向中国大陆正式运营并投放广告时，需自行确认 ICP 备案与平台规则；
- 微信内直接打开第三方域名可能被拦截，建议公众号为主入口、站点为落地页。

## 数据与统计

页面没有任何后端请求，作答只存在浏览器内存里，刷新即清空。需要看流量时自行在 `<head>` 加统计脚本；代码已预留 `track()` 埋点，事件名包括 `finish_quiz`、`unlock_click`。

## 二次开发

题库在 `assets/quiz-data.js` 的 `QUESTIONS` 数组里，每题包含题面、维度、正/反向标记、对各原型的权重。改题后务必重跑 16 种组合，确认每种变体都可达。
